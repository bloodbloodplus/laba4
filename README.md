# Домашнее задание к работе 4

## Условие задачи

В игре три героя (**A, B, C**) атакуют босса. Их специальная способность **«Тройной удар»** активируется только в том случае, если уровень силы **каждого из трёх героев кратен трём**. Запишите условие активации способности.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало.**

2. Объявить переменные `A`, `B`, `C`.

3. **Ввести** уровень силы первого героя `A`.

4. **Ввести** уровень силы второго героя `B`.

5. **Ввести** уровень силы третьего героя `C`.

6. Проверить, являются ли все три уровня силы кратными трём:

   **(A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)**

7. Если условие выполняется:

   - активировать способность **«Тройной удар»**;
   - **вывести** сообщение: «Способность "Тройной удар" активирована!».

8. Если условие не выполняется:

   - **вывести** сообщение: «Способность "Тройной удар" не активирована.».

9. **Конец.**
